One sentence, up to 200 characters, on a small moment of wonder in
everyday life — judged pairwise by an AI judge that rewards surprise.

## The entry

> The water jug gulps once after I fill my glass, as if the kitchen were drinking behind my back.

The angle: the water dispenser everyone ignores makes one loud gulp
after you fill your glass — and for a second the kitchen itself seems
to be drinking, behind your back. A real, specific, everyday sound,
turned strange in a single read.

## Run

```sh
python3 main.py            # writes /output/entry.txt
OUTPUT_DIR=/tmp/out python3 main.py   # write somewhere else
```

`main.py` uses only the Python standard library (`os`, `sys`). It
asserts the entry is one sentence of 1–200 characters, not only
whitespace, valid UTF-8, then writes it with no trailing newline and
reads it back to prove the file is byte-identical.
